# Optional PR review prompts

This is review guidance, not a Git/CI admission gate.

- Is the scope and reason clear?
- Are affected native checks documented with their actual results?
- Are secrets and product/deploy boundaries preserved?
- Are material recovery/guard changes traceable through the local DOCSYNC map?
- Is rollback concrete?
- Are source-only, published, installed, deployed and accepted states distinct?

A missing controller, memory receipt, capsule, selector or Plan-ID never blocks
native source work. No checklist or local PASS grants live authority.
